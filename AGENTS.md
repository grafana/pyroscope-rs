# pyroscope-rs

# Pre-Commit Checks

Before committing, always run:

```bash
cargo fmt --all
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

All must pass with no errors before creating a commit.

# Documentation

User-facing documentation belongs in the `grafana/pyroscope` repository:
https://github.com/grafana/pyroscope

Keep this README focused on the project overview and links. Add detailed setup,
backend usage, platform limits, and troubleshooting guides to that repository's
documentation. Maintain Rust API documentation and compilable examples here.

# Release Notes and Integration Tests

`CHANGELOG.md` is generated by release-please. Use Conventional Commit PR
titles so release-please records changes; do not edit the changelog manually.

Container orchestration for server integration tests belongs in the `e2e` Go
module. Test Pyroscope v2 mode; keep Rust allocator and profile assertions in
the Rust tests rather than adding shell scripts for orchestration.
